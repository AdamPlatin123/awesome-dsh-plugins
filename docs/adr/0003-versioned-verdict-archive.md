# 版本化判定与档案区

全量清单（PLUGINS-ALL.md）的判定从单一值升级为**带版本锚的结论**：每条目关联「插件最新版本 × 兼容判定」，以静态文本锚（如 `✅@v1.2·rc.8`）或轻量表格呈现；不采用动态 shields 徽章——数千条目的外部徽章请求会拖垮页面渲染。版本锚数据全部现成：results 的 input_hash 锚插件版本、runner_image_digest 锚 DSH/测试环境版本、快照 run_id 锚轮次。PLUGINS.md 判定列的来源标记（实测/自报，见 CONTEXT.md）与版本锚正交叠加。

**档案区（陈旧低星仓的归宿）**：不物理删除，降级到 PLUGINS-ALL 尾部的档案分组（保留最后版本锚），数据完整保留在快照基线（ADR-0002）。入档条件只有两项：**无推送时长 ≥ 窗口阈值 且 star < 5**。窗口分两阶段：存量清理期（本决议生效起）为 **2 周**；存量清完后转入常态化的 **6 个月**（切换以档案区规模趋稳为准）。**最后实测时间不参与入档判定**——实测新旧是展示维度（版本锚），不是活跃度信号。出档条件：star 升至 ≥5 或仓库恢复推送（下轮发现自动出档重测）。
